Условия использования сервиса Task Tracker

1. Общие положения

1.1. Настоящие Условия использования (далее — «Условия») регулируют отношения между администрацией сервиса Task Tracker (далее — «Сервис») и пользователем (далее — «Пользователь») при использовании веб-приложения Task Tracker.

1.2. Используя Сервис, Пользователь подтверждает, что ознакомился с настоящими Условиями, понимает их и соглашается соблюдать их.

1.3. Сервис предоставляется «как есть» и администрация не гарантирует бесперебойную работу Сервиса или его отдельных компонентов.

2. Регистрация и учетная запись

2.1. Для использования всех функций Сервиса Пользователю необходимо зарегистрироваться, создав учетную запись.

2.2. При регистрации Пользователь обязуется предоставлять достоверную и полную информацию о себе.

2.3. Пользователь несет ответственность за сохранность своих учетных данных (логина и пароля). Все действия, совершенные с использованием учетной записи Пользователя, считаются совершенными этим Пользователем.

2.4. Запрещается передавать свою учетную запись третьим лицам.

3. Использование Сервиса

3.1. Пользователь имеет право использовать Сервис для:

  • Создания и управления учебными заданиями
  • Организации заданий по предметам и категориям
  • Отслеживания сроков выполнения заданий
  • Просмотра статистики и аналитики

3.2. Пользователю запрещается:

  • Использовать Сервис для незаконной деятельности
  • Размещать вредоносный код или вирусы
  • Попытка получить несанкционированный доступ к данным других пользователей
  • Нарушать работу Сервиса или его компонентов
  • Размещать контент, нарушающий права третьих лиц

4. Ответственность

4.1. Администрация Сервиса не несет ответственности за:

  • Потерю данных Пользователя по техническим причинам
  • Неправильное использование Пользователем функций Сервиса
  • Ущерб, причиненный в результате использования или невозможности использования Сервиса
  • Действия третьих лиц, нарушающих работу Сервиса

4.2. Пользователь несет полную ответственность за содержание создаваемых им заданий и другой информации.

5. Изменения условий

5.1. Администрация оставляет за собой право вносить изменения в настоящие Условия.

5.2. Изменения вступают в силу с момента их публикации на данной странице.

5.3. Продолжение использования Сервиса после внесения изменений означает согласие Пользователя с новыми условиями.

6. Прекращение доступа

6.1. Администрация вправе приостановить или прекратить доступ Пользователя к Сервису в случае:

  • Нарушения настоящих Условий
  • Попытки несанкционированного доступа
  • Действий, угрожающих безопасности Сервиса
  • По решению суда или уполномоченных органов
