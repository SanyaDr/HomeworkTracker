 # О проекте
 ## Что это и зачем
 `HomeworkTracker` - современный электронный журнал для студентов и школьников. Сервис позволяет удобно отслеживать ваши домашние задания, дедлайны по выбранным вами предметам. Заносите свою домашку, добавляйте дедлайны, а сервис уведомит вас о сдаче.

 # Как запустить
 _Далее следует инструкция по установке Git и Python. Если они уже установлены, переходите сразу к [зависимостям](#Установка-зависимостей)_
 ## Установка компонентов
 ### Установка Git
 - __Windows__. Скачайте [Git для Windows](https://git-scm.com/download/win), запустите exe-файл, следуйте инструкциям.
- __macOS__. Скачайте [Git для macOS](https://sourceforge.net/projects/git-osx-installer/) и запустите dmg-файл. Если он не запускается, зайдите в Системные настройки — Безопасность и нажмите кнопку Open anyway (Всё равно открыть).
- __Linux__. Установите Git через встроенный менеджер пакетов. Если у вас Ubuntu, используйте команду `sudo apt-get install git`. Команды для других дистрибутивов можно посмотреть [здесь](https://git-scm.com/download/linux).

### Установка Python
  - __Windows__. Скачайте [устновочный файл](https://www.python.org/downloads/windows/) с официального сайта. Запустите exe-файл. На первом экране отметьте галочку _Add Python to PATH_. Следуйте дальнейшим инструкциям.
  - __macOS__. Скачайте [установочный файл](https://www.python.org/downloads/macos/), запустите pkg-файл, следуйте дальнейшим инструкциям.
  - __Linux__. Установите _Python3_ с помощью консоли `sudo apt install python3 python3-pip python3-venv`.

## Окружение
 Осталось немного. Скачать проект, установить зависимости и готово!
### Клонируем репозиторий
 Откройте командную консоль и вставьте команду:
 
 ```bash
 git clone https://github.com/SanyaDr/HomeworkTracker.git
```

### Установка зависимостей
 Далее, вам необходимо открыть в консоли место расположения проекта. Используйте команду:
 ```bash
 cd HomeworkTracker
```
 Где _HomeworkTracker_ - это путь к корневой папке проекта, у вас он может отличаться, в зависимости от того куда вы клонировали репозиторий.
 
 Установим зависимости:
 ```bash
 python3 -m venv .venv
 source .venv/bin/activate
 pip install -r requirements.txt
 ```

Если виртуальное окружение python успешно установилось, в начале строки ввода, вы увидете `(.venv)`

Поздравляем! Осталось только запустить.

## Запуск
Для удобного запуска сервиса, в корне проекта есть файл __run.py__, запускать проект будем через него.

 ```bash
python run.py
 ```

Если все пройдет успешно, в консоли вы увидите: `[START] Запуск Homework Tracker...`

Далее последует вывод некоторых настроек: хост, порт, путь к документации.

# Использование сервиса
 Для удобства пользователя, у `HomeworkTracker` реализован удобный веб-интерфейс. Открыв в браузере главный эндпоинт: например `localhost:8000` или `127.0.0.1:8000`, вы увидите главную страницу сайта, где вы можете узнать больше о проекте, зарегистрироваться и начать пользоваться!

 Так же возможно использование сервиса с помощью api _ручек_. Их документацию вы можете найти по пути `api/docs`.

# Настройки
 При первом запуске `HomeworkTracker` использует настройки по умолчанию, которые вы можете изменить в файлах конфигурации, часть которых лежит в `config.py`, часть в `.env` файле.

## Config.py
 В директории `HomeworkTracker/backend/app/core` лежит файл `config.py`.
 Он содержит константы по умолчанию для запуска сервера:
 - **_publicPaths_** - список публичных страниц доступных без входа в аккаунт. (если вы не добавляли новых публичных страниц, то лучше оставить так как есть)
 - **_LOG_DIR_** - Название директории где будут храниться логи об критических ошибках. (логи разделяются по дням и очищаются каждые _LOG_RETENTION_DAYS_ дней)
 - **_LOG_RETENTION_DAYS_** - Количество дней, сколько будут храниться логи
 - **_DATE_FORMAT_** и **_TIME_FORMAT_** - Формат даты и времени для логов

 Однако, наиболее важные конфиденциальные настройки считываются из `.env` файла

## Env
 В `.env` файле хранятся данные которыми нельзя выкладывать в публичный доступ, например _секретный ключ шифрования_. Когда вы только клонировали репозиторий, этот файл может вообще отсутствовать - это _нормально_, просто создайте его. 
 Создайте `.env` файл в корне проекта, прямо в `HomeworkTracker`. Туда вы спокойно можете записать поля:
 ```.env
# ==================== НАСТРОЙКИ СЕРВЕРА ====================
ENVIRONMENT=development
HOST=0.0.0.0
PORT=8000
RELOAD=True
LOG_LEVEL=info

# ==================== АУТЕНТИФИКАЦИЯ ====================
SECRET_KEY=your_secret_key
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=90
```

 Пройдемся по каждому и узнаем за что они отвечают:
- `HOST`, `PORT` - Базовые настройки сервера. От них зависит по какому пути вы найдете их в браузере.
- `ENVIRONMENT`, `RELOAD` - Для тестирования оставьте `development` и `True` как в примере выше. Но **для продакшена** присвойте полям значения: `production` и `False`.
- `LOG_LEVEL` - Какой уровень логов будет отображаться в консоли. Например `info` будет выводить практически все что будет обрабатывать сервер, удобно для разработки. В продакшене или просто если не хотите отслеживать каждое действие, установите значение `error`.
- `SECRET_KEY` - 32-символьный ключ безопасности. От него зависит безопасность ваших пользователей. **Никто не должен узнать этот ключ!**
- `ACCESS_TOKEN_EXP`
